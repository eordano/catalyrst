# H1-03 · Below 8 recurring participants a session does not repeat

- **IF/THEN:** IF a session runs with fewer than 8 recurring participants, THEN it fails to produce a second session with the same group.
- **Source section:** §3 Hypotheses
- **Cheapest killing test:** count group size against second-session return on the first open-ground cohorts; one small group that keeps returning kills this.
- **Key metric:** second-session same-group return by group size
