`pixelwars-hypotheses/` is the experiment tree that shipped inside the Pixelwars design zip:
twelve `H<stage>-<nn>-<slug>_<status>.md` files across two stage folders. The status of each
hypothesis is its filename suffix and nothing else — that is the state machine the skill
maintains, and `foundry:import-gdd` reads it rather than the prose. Both Pixelwars versions
point at this one directory because the v2 zip shipped a byte-identical tree.

The Alien Human Zoo draft shipped without an experiment tree, so it imports with an empty
hypothesis log. Its Appendix A is prose that the skill had not yet generated files for, and
we do not manufacture rows out of it.

open-ground-game-clubs-v1.md was drafted by this repository's program on 2026-08-17 — not
imported from anywhere and reviewed by no human. Everything it claims is one of: the two
request rows it links, the shelf-reading counts on /foundry/play, or the deck excerpts on
/foundry/deck. open-ground-game-clubs-hypotheses/ is its experiment tree: three H1 files,
all parked, statuses in filenames as always.

Import with:

    npm run foundry:import-gdd -- packages/data/src/fixtures/gdd/*.md --db "$FOUNDRY_DATABASE_URL"
